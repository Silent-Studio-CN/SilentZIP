> Это краткая версия. Подробности — в [английской](README.en.md) или [китайской](README.md) версии.

Менеджер архивов для macOS. Двойной клик по архиву — и видно, что внутри. Распаковывать заранее не нужно.

Слева папки, справа содержимое архива. Разделитель можно перетаскивать.

---

## Движок

Ядро сжатия — 7-Zip. Официальная сборка для macOS отстаёт от исходников, поэтому собираем сами.

    ./7z-build/build-7zip.sh

Скрипт находит последний релиз на GitHub, скачивает исходники, собирает их clang'ом и кладёт результат в `Resources/7zz`.

Бинарник универсальный (arm64 + x86_64), работает и на Intel Mac.

---

## Возможности

- **Просмотр** — две панели: файлы и содержимое архива
- **Распаковка** — только выбранного. Если ничего не выбрано, появится подсказка
- **Сжатие** — 7z / zip / tar / gz / xz / bz2
- **Проверка** — контроль целостности с отчётом
- **Добавление, удаление, перемещение** — правка внутри архива
- **Вложенность** — открыть архив внутри архива
- **Перетаскивание** — вытащить файл в Finder

Системные каталоги (/System, /usr и подобные) доступны только для чтения.

---

## Работает сразу после установки

При первом запуске автоматически:

- 10 форматов архивов открываются через SilentZIP
- Регистрируются службы Finder

Пароль администратора не нужен, в настройки лезть не придётся.

## Командная строка

Внутри приложения есть `sz`:

    sz list    archive.7z
    sz extract archive.7z ./out
    sz create  new.zip file1 file2
    sz test    archive.7z

Добавить в PATH можно через меню **SilentZIP → Установить утилиту командной строки…**
