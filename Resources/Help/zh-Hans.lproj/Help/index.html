SilentZIP 帮助

macOS 上的归档工具。浏览、压缩、解压，中文界面。

快速开始

  1. 打开归档：把 .7z .zip .rar 拖到窗口里，或 ⌘O
  2. 看内容：左边是本地文件，右边是归档内部，双击进目录
  3. 解压：选中要的东西，点工具栏的「解压」

界面分左右两栏

位置内容
左栏本地磁盘，可以随便进出目录
右栏打开的归档内部，未打开时显示「未打开归档」

选中一个归档文件按 Enter，它就会在右栏打开。

压缩

选中左栏的文件或文件夹，点工具栏的「压缩」，弹出参数对话框：

参数说明
压缩格式7z / zip / tar / wim / gz
压缩等级0 仅存储 · 1 极速 · 3 快速 · 5 标准 · 7 最大 · 9 极限
压缩方法跟着格式变：7z 有 LZMA2 / LZMA / PPMd / BZip2 / Deflate
字典大小64KB 到 1.5GB，档位越细压缩率越高也越吃内存
单词大小5 到 273，文本多的包里调大一点
固实大小把多个文件拼成一块压，压缩率高但随机读取慢
CPU 线程自动 = 用满所有核心
分卷大小填 100m 1g 切成多卷，留空不分卷
更新方式添加并替换 / 添加并更新 / 更新并添加 / 同步 / 仅添加
路径模式相对 / 绝对 / 完整
密码7z 支持 AES-256，还能加密文件名
内存那行会实时算：「36 GB 内存 · 约需 3072 MB」，超过本机内存会变橙色提醒。

长任务的进度条

压缩或解压大文件时，窗口底部出现进度条，右边三个按钮：

  • 暂停 — 冻结进程，不占 CPU，点「继续」接着跑
  • 后台 — 让系统把它当后台任务，前台不卡，速度慢一些
  • 取消 — 终止，已经写出的部分不完整

压 2GB 以上的包、同时还要干别的，建议开「后台」。

解压

  • 选中条目点「解压」→ 只解选中的
  • 右键「全部解压」→ 整个包都出来
  • 拖到 Finder → 直接把条目导出到桌面或文件夹

命令行

sz list    <归档>              列出内容        (l)
sz extract <归档> [目录]       解压            (x)
sz create  <归档> <文件...>    创建归档        (a)
sz test    <归档>              校验完整性      (t)
sz info    <归档>              归档信息        (i)
sz version                    版本            (v)

首次使用要先装：菜单「工具 → 安装命令行工具…」，会建一个软链到 /usr/local/bin/sz。

命令叫 sz 不是 silentzip：macOS 文件系统不区分大小写，SilentZIP 和 silentzip 是同一个文件，用全名会把主程序覆盖掉。

支持哪些格式

引擎内置 60 多种，常用的：

7z zip rar tar gz bz2 xz zst lzh cab iso arj cpio dmg jar apk

常见问题

双击压缩包没反应

菜单「工具 → 设为默认压缩工具」重新注册一次。

提示密码错误

7z 加密的包如果是「加密文件名」模式，密码不对会直接打不开，而不是提示输入密码。

装了之后 zsh 里找不到 sz

sudo ln -sf /Applications/SilentZIP.app/Contents/MacOS/sz /usr/local/bin/sz

切换语言后界面没变

会重启一次。语言文件是启动时读进内存的，已经画好的界面不会自己重绘。

完全卸载

rm -rf /Applications/SilentZIP.app
sudo rm -f /usr/local/bin/sz
defaults delete cn.silentstudio.silentzip
rm -rf ~/Library/Application\ Support/SilentZIP
