SilentZIP Help

An archive tool for macOS. Browse, compress, extract.

Getting started

  1. Open an archive: drop a .7z .zip .rar onto the window, or press ⌘O
  2. Look inside: local files on the left, archive contents on the right. Double-click to enter a folder
  3. Extract: select what you want, then click Extract in the toolbar

Two panes

PaneShows
LeftYour disk. Navigate freely.
RightInside the opened archive. Says "No archive open" until you open one.

Select an archive and press Enter to open it in the right pane.

Compressing

Select files or folders on the left, click Compress, and the parameter dialog appears:

ParameterMeaning
Format7z / zip / tar / wim / gz
Level0 Store · 1 Fastest · 3 Fast · 5 Normal · 7 Maximum · 9 Ultra
MethodFollows the format: 7z offers LZMA2 / LZMA / PPMd / BZip2 / Deflate
Dictionary64KB to 1.5GB. Bigger means better ratio and more RAM.
Word size5 to 273. Raise it for text-heavy archives.
Solid blockPacks files into one block: better ratio, slower random access
CPU threadsAuto uses every core
Volume sizeEnter 100m or 1g to split. Leave empty for one file.
Update modeAdd and replace / Add and update / Update and add / Synchronize / Add only
Path modeRelative / Absolute / Full
Password7z supports AES-256, and can encrypt file names too
The memory line updates live: "36 GB RAM · needs 3072 MB". It turns orange when the estimate exceeds your RAM.

Progress, pause, background

For big jobs a progress bar appears at the bottom of the window with three buttons:

  • Pause — freezes the process, uses no CPU. Resume continues where it stopped.
  • Background — the system treats it as a background task. The UI stays smooth, it runs slower.
  • Cancel — stops it. Whatever was already written is incomplete.

For 2GB+ archives while you keep working, turn on Background.

Extracting

  • Select entries, click Extract → only the selection is extracted
  • Right-click → Extract All → everything comes out
  • Drag to Finder → drops the entry where you let go

Command line

sz list    <archive>              list contents   (l)
sz extract <archive> [dir]        extract         (x)
sz create  <archive> <files...>   create archive  (a)
sz test    <archive>              verify          (t)
sz info    <archive>              archive info    (i)
sz version                        version         (v)

Install it first: menu Tools → Install Command Line Tool… It symlinks to /usr/local/bin/sz.

The command is sz, not silentzip: macOS filesystems are case-insensitive, so SilentZIP and silentzip are the same file — the full name would overwrite the main binary.

Supported formats

The engine handles 60+. Common ones:

7z zip rar tar gz bz2 xz zst lzh cab iso arj cpio dmg jar apk

Troubleshooting

Double-clicking an archive does nothing

Menu Tools → Set as Default Archive Tool to re-register.

It says the password is wrong

If the archive also encrypts file names, a wrong password makes it unopenable rather than prompting.

zsh can't find sz

sudo ln -sf /Applications/SilentZIP.app/Contents/MacOS/sz /usr/local/bin/sz

Switching language didn't change the UI

It restarts once. Language files are read into memory at launch; an already-drawn interface won't repaint itself.

Uninstalling completely

rm -rf /Applications/SilentZIP.app
sudo rm -f /usr/local/bin/sz
defaults delete cn.silentstudio.silentzip
rm -rf ~/Library/Application\ Support/SilentZIP
