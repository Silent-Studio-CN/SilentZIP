## 想加一门新语言

1. 复制 `README.en.md`，改名成 `README.<语言代码>.md`
2. 翻译内容
3. 在这个表格里加一行
4. 提交 PR

语言代码用 BCP 47：`es`（西班牙语）、`pt`（葡萄牙语）、`it`（意大利语）、`zh-Hant`（繁體中文）等。
